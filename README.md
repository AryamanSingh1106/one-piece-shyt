# Meet the Straw Hats

A cinematic, scroll-driven One Piece fan site (three.js + GSAP ScrollTrigger).

## Run it
Open `index.html` in a modern browser (Chrome/Edge/Firefox). It is a single self-contained file:
all images, music, the font, the ocean frames and the 3D hat are embedded. It only loads
three.js / GSAP / Google Fonts from CDNs, so you need an internet connection.
Tap the vinyl disc in the hero to start the music.

## What is in `assets/`
Copies of everything embedded in `index.html`, for reuse or editing:
cutouts (crew + ship + jolly roger), wanted posters, the 120 ocean frames, the three music
tracks (trimmed), the One Piece font, and the packed straw-hat mesh data.
